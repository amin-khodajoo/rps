# بازی سنگ، کاغذ، قیچی

یک بازی ساده و تعاملی **سنگ، کاغذ، قیچی** است که با استفاده از **JavaScript** ساخته شده است.  
در این بازی، بازیکن می‌تواند با کامپیوتر رقابت کند و نتیجه هر دور به صورت لحظه‌ای نمایش داده می‌شود.

این پروژه به من کمک کرد تا مهارت‌های برنامه‌نویسی جاوااسکریپت و منطق شرطی را بهبود دهم.

---

## ویژگی‌ها

- انتخاب‌های بازیکن و کامپیوتر  
- اعلام برنده هر دور  
- طراحی ساده و کاربردی
